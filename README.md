# NSHIR (نشر)

منصة إعلانات مبوبة عربية خفيفة وسريعة على `nshir.com`.

## مبادئ المنتج
- التصفح حسب الموقع الجغرافي والتصنيف، كلٌ بشكل مستقل أو مجتمعين.
- موقع الإعلان يأتي من بروفايل العضو ولا يُطلب داخل نموذج النشر.
- زر «نشر إعلان» يقود المستخدم خلال شجرة التصنيفات حتى آخر تصنيف فقط.
- نموذج الإعلان: العنوان، المحتوى، السعر، الصور.
- عرض قائمة أو كروت مع تصفح صور الإعلان.
- تسجيل بالبريد والاسم وكلمة مرور (8 خانات على الأقل)، تفعيل واستعادة عبر البريد.
- تصميم server-rendered خفيف وصديق لمحركات البحث.

> التطوير الفعلي يتم عبر فروع وطلبات دمج.
